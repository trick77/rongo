# The code-terms text gets its own keyword rung; a second FTS column for identifiers does not ship

**Status: measured 2026-09-15 and 2026-09-16 on the pinned Go corpus (deterministic arms once, reranked arms twice) and the flow corpus (twice). The code rung at 0.8 ships as the product default. The identifier column is a wash at the cut and worse on mean rank, and would cost every deployment a rebuilt FTS table and a full re-index, so it is removed from the branch and kept here as a table.**

## Why

`chunks_fts` is one bare column over the raw text with the unicode61 tokenizer: camelCase never splits and the repository, path and symbol breadcrumb live only in the embedded text. The hypothesis was that a reader's word ("cart") could reach `AbandonedCartJob` through the keyword lane if the identifier were split into words in a second, lower-weighted column. A second observation fell out of reading the ladder: the understanding step's code-terms text (three to eight guessed identifiers) is ANDed by the strict, content and prefix rungs, which are expected to return nothing and be skipped, so that text only ever entered fusion through the OR floor at 0.4, below the semantic lane's 0.6. That reading of the ladder was not measured per rung: no arm counted how often each rung of the code text comes back empty, and the tables below say what the reweighted floor is worth, not that the rungs above it never fire.

## What it says

- **The rung is cheap and consistent.** One more weighted lane over a query that already runs; a deterministic gain at five, at twenty and on mean rank; one question at twenty on the reranked path in both runs. Not a large move, and read together with 2026-09-16-rerank-excerpt.md: the two ship together.
- **The identifier column does not earn a schema change.** It found nothing the vector lane did not, and it pushed the expected chunk down by pulling in every chunk of a repository through its path words. Deterministic derivation, never model text, so nothing here touches the invariant on model-written summaries; it simply did not help.
- Not measured: the answer judge with the rung on. The change is in what is gathered.
